Introduction

Drug Attrition Oracle is a graph neural network (DNN) model based on the chemical structure of compounds. The model is built by using a set of around 2000 approved and 300 withdrawn drugs. DAO predicts the probability for a small molecular weight compound to be withdrawn (in the hypothetical case) once it is approved as a drug on the market. It can also be used for already approved drugs on the market. The model provides an additional interpretable layer through the GNN Explainer which identifies chemical substructures that are most influential for making the prediction. The model takes as an input the SMILES structure (string) of a molecule and outputs a conformal withdrawn/approved prediction along with a confidence score. The GCN prediction is further used as a feature for the XGBoost Complementary model, which includes additional 4 ADME/Tox parameters predicted by GCN-based models developed on Therapeutics Data Commons TDC data.

Data

The data set of approved ˙(around 2500) and withdrawn (around 300) organic drugs has been built by merging data from publicly available databases like ChEMBL, KeGG (Kyoto Encyclopedia of Genes and Genomes) Drugbank and Withdrawn, Wikipedia and comparison with other relevant free resources and databases. The set is composed of organic chemical compounds with the molecular weight in the range 30-2000. For merging data, data cleaning as well input standardization, the canonical SMILES generated by the program ADMET Predictor (Simulation Plus) were applied. Finally, the SMILES inputs were transformed to canonical form by using the standardiser package (https://pypi.org/project/standardiser/). The Anatomical Therapeutic Chemical (ATC) classification data were collected from the databases ChEMBL and KEGG. The ADME and toxicity datasets were downloaded from Therapeutics Data Commons and Tox21 dataset.

GCN Model

Drug Attrition Oracle GCN Model is a graph convolutional neural network that takes SMILES strings of compounds as an input and provides a prediction of the probability that a small molecular weight compound could be withdrawn from the market. The model outputs an uncertainty estimation in the form of a conformal prediction. Explanations are generated by GNN explainer which is a model-agnostic approach for providing interpretable explanation. GNN explainer provides a local interpretation by highlighting relevant atom features as well as important subgraph structure in the input compound.

Complementary model

The XGBoost model was used to improve the performance of the GCN model. The model combines the GCN output with molecular/drug properties Bioavailability, Clearance Hepatocyte, CYP2C9 Substrate and Toxicity (nr-ppar-gamma activation), which are predicted by graph neural network models trained on Therapeutics Data commons datasets. The contribution of absorption, metabolism, excretion and toxicity to the prediction is visualized by using SHAP values for the most significant parameters Bioavailability, Hepatocyte Clearance, CYP2C9 Substrate and nr-ppar-gamma activating potential (nuclear receptor Peroxisome proliferator-activated receptor gamma), respectively.
